# Dr. Ratshulumela Nanga ya Ndevhe  

## Overview
A modern, responsive single-page website for Dr Ratshulumela Nanga ya Ndevhe, a professional Hearing Aid Acoustician and Audiologist.

## Features
- Clean, modern design
- Full mobile responsiveness
- Dark mode and light mode
- Smooth scroll animations
- Sections: Home, About, Services, Locations, Contact
- Book Appointment button

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Font Awesome Icons



## Customization
- Modify content in `index.html`
- Adjust styles in `styles.css`
- Update interactions in `script.js`
